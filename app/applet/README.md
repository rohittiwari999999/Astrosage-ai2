# AstroSage AI (वैदिक ज्योतिष एवं राशिफल)

A modern, high-precision Vedic Astrology Android application powered by Swiss Ephemeris calculations and Gemini AI.

## 📱 Download Test APK & Play Store AAB

Whenever code is updated or you click **Actions > Run workflow** on GitHub:
1. Go to the **[Actions tab](../../actions)** in this repository.
2. Click on the latest workflow run.
3. Scroll down to **Artifacts** to download:
   - **`AstroSage-Test-APK`**: Directly installable APK on any Android phone.
   - **`AstroSage-PlayStore-AAB`**: Android App Bundle ready to upload to Google Play Console.

## ✨ Key Features
- **Lagna & Kundali Generation**: High-precision Nirayana planetary positions (Lahiri Ayanamsha) computed via astronomical ephemeris.
- **24 Kundali Divisional Charts**: Navamsha, Chalit, Moon chart, Shodashvarga, Lal Kitab, Varshphal, and KP Sub-lords.
- **Vimshottari Dasha (120 Years)**: Detailed Mahadashas and active Antardashas.
- **Dosha Analysis & Vedic Remedies**: Manglik Dosha, Kaal Sarp Yoga, and Shani Sade Sati analysis with classical remedies.
- **36 Guna Kundli Matching**: Ashtakoota compatibility scoring for marriage.
- **Daily Panchang & Rashifal**: Tithi, Vaar, Nakshatra, Yoga, Karana, Rahu Kaal, and 12-sign daily horoscope.
- **Acharya AI Vedic Astrologer**: Real-time consultation grounded in the user's exact astronomical coordinates.
- **100% Bilingual**: Seamless switching between Hindi (हिन्दी) and English.
